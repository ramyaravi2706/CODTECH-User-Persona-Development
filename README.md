## Project Overview
The objective of this project is to create a user persona for an online shopping application by understanding the user's background, goals, needs, preferences, and challenges.

## Project Scope
This project focuses on identifying a target user and representing their characteristics through a visual user persona.

## Work Done
1. Created a user persona for an online shopping application.
2. Added personal details such as name, age, occupation, and location.
3. Described the user's bio and personality.
4. Identified the user's goals and needs.
5. Listed common shopping challenges and pain points.
6. Added popular online shopping brand logos using Google Images.
7. Organized the information with suitable colours, icons, and layouts.
8. Exported the final design as a PNG image.
